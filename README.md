# Student Management API

## Overview

Student Management API is my first RESTful API project built with ASP.NET Core after learning REST principles.

The project focuses on applying clean architecture concepts, organizing code into layers, and building CRUD operations using best practices.

**Completion Date:** January 2026

---

## Technologies

- ASP.NET Core Web API
- C#
- SQL Server
- ADO.NET
- 3-Tier Architecture
- RESTful API
- DTOs


---

## Architecture

The project follows a 3-Tier Architecture:

- **Presentation Layer** → API Controllers
- **Business Layer** → Business Logic
- **Data Access Layer** → Database Operations

---

## Features

- Add New Student
- Update Student
- Delete Student
- Get All Students
- Get Student By ID
- Upload Student Image
